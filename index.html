YouTube Data API Key

ใช้สำหรับค้นหาเพลงและแนะนำเพลงขณะพิมพ์ หากไม่มี Key ยังสามารถเพิ่มเพลงด้วยลิงก์ได้ โดยตั้งค่าแยกกันในแต่ละอุปกรณ์

  1. เข้า Google Cloud Console และเลือกหรือสร้างโปรเจกต์
  2. เปิดใช้งาน YouTube Data API v3
  3. สร้าง Credentials → API key
  4. จำกัด Key ให้ใช้เฉพาะ YouTube Data API v3 และ HTTP referrers ของเว็บที่คุณเผยแพร่

Key เก็บในเบราว์เซอร์เครื่องนี้ ไม่ส่งต่อให้รีโมทอื่น แต่ Key ที่ใช้ในเว็บฝั่งผู้ใช้ไม่สามารถซ่อนเป็นความลับได้ ควรจำกัดสิทธิ์และตรวจสอบโควตา
