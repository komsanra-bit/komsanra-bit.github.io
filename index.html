YouTube Data API Key

การตั้งค่า YouTube API Key ช่วยให้คุณสามารถค้นหาเพลงคาราโอเกะได้โดยตรงภายในแอปพลิเคชัน (หากไม่ใส่ สามารถวางลิงก์ YouTube จากแอปอื่นได้):

วิธีขอ API Key ฟรี:

  1. ไปที่ Google Cloud Console (console.cloud.google.com)
  2. เปิดใช้งาน "YouTube Data API v3"
  3. สร้าง Credentials -> API Key นำมาคัดลอกใส่ในช่องด้านบน
